#15420 · Markerless v-for hydration anchors become a local decision

Core conclusion: when a tagged TransitionGroup hydrates SSR children whose outer fragment markers were flattened away, it now supplies only the active markerless container. createFor() owns the anchor decision: create one when the list truly has no close marker, or reuse the preserved <!--]--> when slot content kept it. That removes a reverse callback dependency and fixes the trailing-sibling case without adding a redundant marker.
