# 审读方法

## 先确定正在判断什么

抓取原文、发布日期和必要上下文，区分原作者、引用对象、评论者。截图里的数字可转成待核查主张，但数字与行情相符不能证明截图或交易真实。线程编号或 ID 间隔不能证明抓取完整。

只有摘要、转述或截图局部时，标明覆盖范围；可以审查已见内容的内部推理，不能声称核验了完整原文。无法访问原文时，寻找合法可访问的副本或一手材料；关键缺口仍在，就说明还需要哪一段材料。搜索摘要用于发现线索，不能单独承担决定性证据。

优先处理支撑主结论的前提，以及可能成为有用知识的独立主张，不必逐句穷举。分别识别：

- 事实：对象、时间、单位、样本、比较基线是什么？
- 机制或因果：从前提到结果经过哪些环节，哪些已经观测，哪些仍是假设？
- 预测：对象、时间窗口、条件、可观测结果是什么？未到期不能按已经发生的事实判真伪。
- 动机或价值判断：受益、客观效果、意图和合谋是不同主张；个人偏好不接受简单真假裁决。
- 建议或策略：即使历史叙述为真，是否足以支持其适用对象和可复制性？

忠实复述原命题。必要时分别列出字面表述与合理解释；修补后的论证属于审读者重构，不能冒充作者已经证明。用户提供的线索也需要核验。

## 用第一性原理改变审读方式

对决定结论的机制、因果与可复制性主张，按以下取向组织分析；不将它们当成每篇文章都必须输出的步骤或栏目。单纯核对日期、引文等事实时，直接取证即可。

**先独立理解问题，再评价作者的解释。** 确认原命题范围后，暂时搁置作者的结论、权威与类比，从已知事实出发判断：结果由哪些对象、关系和约束决定？形成足以检验主张的最小机制，再与原论证对照。知识不足就查明关键机制，不为展示独立思考编造另一套故事；成熟模型可借用，但需核对其假设。区分作者论证质量与结论本身的可信度：结论可能成立，即使作者给错了理由。

**寻找决定结果的约束与环节。** 根据问题选择资源上限、流量与存量、信息可得性、参与者选择、制度规则或传导路径等切入点；追到能区分解释的层次即可。物理约束、会计恒等式、可变制度、经验规律和参数估计的证据地位不同，不能统称公理。优先检验一旦改变就会改变结论的关键假设，不无限追问“为什么”，也不默认所有问题最终都由利益或制度解释。

**区分可能发生、实际发生与足以解释。** 有一条作用路径不等于它在当前情境起作用，更不等于它是主导因素。涉及数量时，用量纲、数量级、边界或敏感性分析检验影响是否足以支撑原结论；参数未知就给条件判断。反方提出微小影响，不能据此推翻“不足以主导”的主张；真实且重大的反例也不能被当成枝节排除。

**让机制决定去找什么证据。** 对有依据的竞争解释，寻找它们会产生不同结果的观察、比较或干预；优先核验这一分歧，而非不断增加同方向引用。机制存在、同时变化、先后发生以及利益相容，都不自动证明因果或动机。干预后没有变化也不能独自排除其他解释；检查对象差异、同期因素和时滞。必要时设定反事实以指导取证，明确它是假设推演，不能冒充实际实验结果。

**主动建构，也主动收窄。** 既指出论证断点，也说明在什么前提下合理内核能够成立。修补后的论证标明是审读者重构，不能算成作者已有证据。对支持充分的主结论明确认可，不为了显得严谨枚举无关可能性；对证据不足的解释保留不确定性。若多种机制仍无法区分，就保留竞争解释，不强选一个“底层真相”。

## 证据与结论

一手来源优先，但仍检查测量方法、利益关系、样本、更新和更正。转载同一新闻、引用同一论文或多个 Agent 复述同一数据，都不是独立佐证。来源权威程度与它是否真正支持当前主张，要分别检查。

对重要推断提供可检查的论证概要：决定性前提、机制、证据和结论边界，不必展开全部探索过程。逻辑矛盾或算术错误可以直接指出；具体机制是否在现实中起主导作用，仍需经验材料。

先分别判定关键主张，再写总评。有直接反证或明确违反已核实约束时，可以判定该主张在对应范围内不成立；证据不能区分竞争解释时，应判为尚未证实；前提不足以推出结论时，可以否定这段论证，但不能据此宣布结论本身为假。同一文章中的不同主张可能属于不同状态，不用统一的强判词覆盖它们。

完成正文后核对首段、标题和沉淀：它们不得将“未证明”升级成“已证伪”，也不得将已有明确反证降格为笼统的“不确定”。例如，数学分解可以说明总量变化由哪些部分构成，却未必识别谁造成了这些部分的变化。除非有相应的因果证据，不把前一种结果写成后一种判断。

“事实准确但推论不足”“结论可能成立但原论证不充分”“在这些条件下得到支持”都是有效判决。不要为避免和稀泥而强判，也不要因枝节瑕疵否定核心结论。检查反证是否攻击了原文真正提出的主张，而不是自行加强的版本。

不要为了多角度列出所有学科。选择能补独有证据、检验关键假设或提出有效反例的视角；结论以证据质量收敛，不按人数收敛。

## 涉及数字、统计或回测时

- 对齐时间、币种、存量/流量、名义/实际、总量/人均、样本范围及分母。复算关键数值，披露公式、输入来源、四舍五入和模型假设；不必展示所有中间运算。
- 区分指标与其代理的对象。例如不同产品的份额不能未经净值换算就充当资金流；净申购也不自动等于同日同额的底层现货买入。
- 置信区间、概率和归因比例要有数据与计算或模型依据。缺少依据时用有理由的定性判断，不能把“90% 的事实支撑”解释成统一的概率算法。
- 模型推算标为条件估计；参数适用范围、敏感性和量级上限要与事实观测分开。不能从一个经验案例推出普适必要条件。
- 检验策略先保留原规则。入场、退出或择时条件不明确时，说明不可复现之处；自选固定日期的回测只能检验这个替代版本。
- 选择合适基准、失败样本和决策当时可得的数据，检查前视、幸存者、选择偏差及必要的成本假设。样本内符合不等于样本外有效。

查清高成本实验的最小决定性问题再扩展，不为一篇普通帖自动开展全市场研究。

## 收口和更新

对关键结论说明什么新证据会改变它，不强制每条普通事实都附预测。信息时效影响判断时写清“截至何时”和需要重新核验的条件。

发现错误时，更正具体主张并检查受影响的下游结论与沉淀；报告哪些仍成立。新的解释不能自动继承旧解释的证据强度。继续对话时可提出升级、降级或撤回某条内容；改写外部知识库仍须有相应授权。
