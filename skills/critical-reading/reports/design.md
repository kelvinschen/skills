# 第一版设计记录

日期：2026-09-14。模式：轻量草案，供个人使用。

## 目标与范围

身份：`critical-reading`。目标目录：仓库内 `skills/critical-reading/`，本轮技能写入仅限该目录。Yao Meta Skill 为只读工程工具；不安装、不发布、不迁移其他技能。名称与目录为按仓库惯例采用的可逆默认值。

用户确认的重复任务：对互联网文章、帖子等内容做事实与逻辑审读，并筛选可独立复用的高价值信息。可靠结论与有研究价值但未证实的观点分开保留，不强行提炼、不以用户赞同代替事实依据，标清知识来源。关注认知增量而不追逐新奇；研究深度围绕决定性证据收口。

输出约定：先给整体判断，再呈现值得保留的可靠结论、待验证研究线索和必要缺口，按实际内容省略空栏目。可靠结论带上下文、支持依据、来源归属与适用边界；线索另带研究价值、证据缺口和下一验证方法。默认会话输出，不自动建知识库或生成行动方案。

目标和主要输出已闭合，无核心待决项。用户确认语言统一为中文，Description 保留原文；机器字段、匹配短语和必要技术标识保留原有形式。非核心推断：名称、路径、默认无持久化。无代码执行资产需求，故不添加脚本。

## 参考扫描与取舍

1. 用户提供的三天会话复盘，重点关注 QDII、策略检验和用户纠错方式：保留忠实还原主张、机制拆解、原始数据复核、寻找真实反例。它是二次梳理，不是金融事实的验证基线；不复制私人会话或继承其数据结论。
2. 本次共创决定：在事实核查之外增加内容吸收；不强制产出，独立复用时保留来源与边界；明确可靠知识和研究线索的不同状态。
3. Yao 的工程方法、目标安全与资源边界：采用轻量草案模式、锁定新目录、短入口和按需参考、静态触发检查；不搬入生产发布治理流程。
4. 本地 skill-creator 与仓库技能布局：保持 name/description 可发现、Markdown 入口与 OpenAI 界面元数据；不借用其他技能的决策流程或视觉系统。

不继承：统一 90% 可信门槛、无依据的归因百分比、角色投票、固定多视角数量、替代策略自动背书，以及把改写后的规则回测当成原主张的证伪。

## 输出风险与写作约定

- 风险：将观点写成知识。控制：两类内容明确标注；来源归属与证据状态分开；重复或共识不能升级证据。
- 风险：强行制造信息密度。控制：按独特认知收益筛选，可以零沉淀；不靠删除条件或拆条提高密度。
- 风险：引用正确但推断越界。控制：引用逐项对应主张，观测、假设和模型估计分开，修正结论强度。
- 风险：为显严谨攻击稻草人。控制：保留原主张范围，重构和测试替代版本必须披露。
- 风险：外部信息不全仍给强判决。控制：说明访问覆盖与决定性缺口，不以搜索摘要或复盘替代一手核验。

呈现采用结论在前的中文 Markdown，来源紧随主张，多项判决确有比较价值时才用表格。信息量随证据与用途变化，不生成固定卡片、长篇知识地图或视觉页面。

## 第一性原理指导优化

用户希望在 Agent 已有概念理解之上增加有效指导。本轮将入口中的防误用提醒改为主动重建机制，并在审读方法中加入五个判断取向：独立理解问题、识别决定性约束、区分可能性与影响量级、用机制选择证据、建构合理解释并约束结论强度。它们不构成固定输出模板，不要求对简单事实进行机制推导。

内容吸收同步强调保留可迁移关系及其边界；不把未验证机制升级成可靠知识。Description、触发范围和两类沉淀的证据门槛保持不变。该次修改后先做静态结构与资源检查，不将其视为行为效果证明；随后开展的独立输出评测关注 Agent 能否找到决定性环节，而非仅复述这些指导词，结果见上文链接。

本轮检查：结构校验、资源边界、本地引用与空白字符检查均通过，无失败或警告。当前工具启发式估算入口为 271 个词元、首次加载为 454 个词元；不代表实际模型分词或整次任务的上下文开销。
