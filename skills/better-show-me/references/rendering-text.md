# Show Me 纯文本投影

纯文本与 HTML 使用同一份语义模型。文本依靠顺序、缩进、对齐和稳定符号建立主线。

行尾属性与中括号标签承载入口、分歧、修复点和源码位置；原位注释承载局部补充。

## 基础语法

- 粗体：结论、守卫、终态。
- 行内代码：标识符、路径、字段和值。
- 树线与缩进：层级。
- `→`：推进或数据流。
- `↑` / `↓`：事件上浮与数据下传。
- `+` / `~` / `=`：新增、调整与保持。
- `[入口]`、`[等待]`、`[证据]`：文字状态标签。

## 文本排布

| 表达家族 | 文本投影 |
|---|---|
| 层级 | 缩进与树线；职责、状态、源码锚点跟随节点 |
| 流转 | 编号步骤或单向箭头；标出关键跃迁与 I/O |
| 变化与决策 | 行首 Diff 符号或按共享维度对齐的 Markdown 表格 |
| 定位问题 | 从共同起点缩进展开首个差异，错误与证据贴在断点行 |

## 轻量 Mermaid

关系较少时使用缩进文本；空间关系成为主要问题时使用 Mermaid：`sequenceDiagram` 表达跨实体消息，`flowchart` 表达流程与数据流，`stateDiagram-v2` 表达有限状态，`erDiagram` 表达实体关系。

## UI 视觉

UI 空间关系属于 HTML 专属表达。文本输出使用组件树说明层级、状态所有权与交互方向。

## 完整实现附件

用户需要直接使用时，在解释之后提供标准 fenced code block，并标明文件路径、语言与运行前提。
